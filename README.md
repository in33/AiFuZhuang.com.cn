# AI 服装 · 智能定制工作台

> 把一句「我想要件…」，变成一张可生产的订单。

线上体验：**https://in33.github.io/AiFuZhuang.com.cn/**

一个纯 HTML / CSS / JavaScript 实现的 AI 服装定制工作台 Demo：感性需求六维解构、所见即所得实时预览、动态估价、一键发送远程打印工场——让定制像网购一样简单，像高定一样专业。

## 核心功能

### 智能定制工作台
- **左侧六维配置面板**（选择顺序即洽谈动线）：
  ① 款式（旗袍 / 西装 / 晚礼服 / 大衣 / 衬衫）→ ② 花型（素色 / 提花 / 条纹 / 格纹，仅作用于服装区域、不改变背景）→ ③ 面料（真丝 / 羊绒 / 亚麻 / 丝绒 / 棉布）→ ④ 主色（8 色国风色板）→ ⑤ 廓形（随款式联动，实时调整取景与缩放）→ ⑥ 胸口徽章（LOGO 织唛刺绣，可开关）
- **右侧实时预览**：真实服装照片 + 颜色混合渲染 + 花型叠加（仅作用于服装区域，不改变背景）+ 胸口刺绣徽章
- **动态估价**：款式基价 × 面料系数 + 工艺加价，区间价格实时刷新
- **AI 需求解构**：输入一句话（如「想要一件优雅的旗袍，秋天穿去婚宴」），自动填充全部六维参数，支持示例一键体验

### 设计即生产
- 一键生成中英文 **AI 绘图提示词**，可复用于任意绘图工具
- **发送远程打印工场**：数码直喷 / 热转印 / 激光裁床三类工场选择，设定份数与工艺备注，生成工单号并按「接收 → 排版 → 打印 → 质检 → 出货」五阶段流转留痕

### 体验细节
- 首屏照片堆叠支持**鼠标拖拽旋转与平移视角**（3D 视差）
- 全站暖金 × 深海蓝海派视觉，正向温柔的文案语气

## 项目初心

定制服装是一份关于「被看见」的美好。我们希望用 AI 把这份美好变成每个人触手可及的日常：

- 听懂每一句话 —— 感性描述被轻松转译为专业参数
- 让灵感不必等待 —— 出样更快，热爱不降温
- 好方案值得沉淀 —— 版型 / 面料 / 工艺全部参数化，可检索复用
- 把想象画在眼前 —— 所见即所得，确认变成开心的事

## 技术实现

| 层 | 方案 |
|---|---|
| 结构 / 样式 / 逻辑 | 纯 HTML / CSS / JavaScript，零依赖、零构建 |
| 首屏 3D | CSS 3D 变换 + 指针事件驱动旋转 / 平移 |
| 预览合成 | CSS `mix-blend-mode` 颜色渲染 + `mask-image` 区域限定花型 + SVG 徽章 |
| 部署 | GitHub Pages |

## 目录结构

```
├── index.html      # 页面结构
├── style.css       # 视觉样式（海派金 × 深海蓝）
├── main.js         # 工作台逻辑：配置 / 预览 / 估价 / 解构 / 打印工单
└── assets/         # 示例服装照片（Unsplash 可商用许可）
```

## 本地运行

```bash
python3 -m http.server 8890
# 打开 http://127.0.0.1:8890
```

或直接双击 `index.html`。
